Проверка игры на SkinChanger

Сверка инвентаря в клиенте CS2 с профилем Steam

▼

Регламент действий:

  1. Первым делом просим игрока открыть инвентарь в CS2.
  2. Обязательно, если имеются дорогие скины (ножи, перчатки, редкие скины оружия), переходим в профиль Steam игрока и сверяем инвентарь.
  3. Критическое правило: Если в игре скины есть, а в Steam инвентаре их нет — это 100% доказательство использования стороннего ПО (SkinChanger).
🛑

ВЕРДИКТ: БАН ПО ПРАВИЛУ 1.1

При несовпадении инвентаря выдаем немедленный бан по Правилу 1.1 (Использование стороннего ПО).

Проверка панели управления Nvidia

Управление параметрами 3D ➔ Недавние приложения

▼
  1. Заходим в Панель управления Nvidia (ПКМ по рабочему столу ➔ Nvidia Control Panel).
  2. Переходим в раздел слева: «Управление параметрами 3D».
  3. Выбираем вкладку «Программные настройки».
  4. Нажимаем кнопку «Добавить».
  5. В выпадающем списке Windows отобразит все недавно запускавшиеся программы с 3D-рендером. Если там обнаружено постороннее ПО, чит-клиенты — это прямое подтверждение недавнего запуска!

Everything — Локальный поисковик (3 сигнатуры)

Сигнатурный поиск по каналам Discord сервера Fear-Project

▼

Для работы с Everything нам нужны 3 сигнатуры, представленные в канале #для-проверки Discord сервера Fear-Project:

СИГНАТУРА №1

Файлы / Папки / Приложения

Внимательно просматриваем каждый файл/папку/приложение. В системе могут быть системные файлы со схожим названием — проявляйте внимательность!

СИГНАТУРА №2

Остатки Memesense / Neverlose

Поиск остаточных конфигов, скриптов, луа и дампов. Могут встречаться похожие по названию файлы, но такое бывает довольно редко.

СИГНАТУРА №3

Прямой поиск читов

Глубокий поиск известных чит-пакетов. Сигнатура может найти схожий файл, но это случается крайне редко.

Shellbags — Просмотр истории папок

Обнаружение удаленных и посещенных каталогов читов в реестре

▼
  1. Запускаем утилиту ShellBags.
  2. Снизу нажимаем кнопку «Анализ» и ждем полного сканирования.
  3. В выпадающем списке фильтрации переключаем с «Показать все» на:
    ⭕ Удаленные папки (Deleted Folders)
  4. Здесь мы ищем, в какие папки читов пользователь мог заходить или которые он удалил перед проверкой!

📥 2.3

BrowserDownloadView

В данной программе мы смотрим, что пользователь скачивал через все браузеры (Chrome, Opera, Edge, Yandex и др.).

Инструкция:
1. Заходим в программу.
2. Сортируем по шестому столбцу «Start» (время старта загрузки).
3. Просматриваем скачанные архивы, .dll и .exe файлы.
⏱️ 2.4

LastActivityView

Хронологическая лента событий Windows. Позволяет точно узнать, что запускалось перед CS2.

Инструкция:
1. Сортируем по столбцу «Action Time».
2. Нажимаем Ctrl + F и ищем: cs2.exe и steam.exe.
3. Внимательно смотрим, что запускалось до и сразу после этих процессов!

SystemInformer — Мониторинг памяти CS2

Поиск инжектированных строк «aimbot» и «legit» в памяти cs2.exe

▼

Пошаговый алгоритм сканирования памяти:

1. Ищем процесс cs2.exe в SystemInformer.
2. ПКМ ➔ Properties ➔ вкладка Memory.
3. Нажимаем кнопку Options ➔ Strings...
4. Минимальная длина (Minimum length) ставим: 5.
5. Обязательно ставим галочки: ☑ Image и ☑ Mapped.
6. Ждем окончания сканирования.
7. Нажимаем Filter ➔ Contains (case-insensitive).

JournalTrace — Журнал низкоуровневых событий

Анализ журнала изменений файловой системы NTFS

▼

Скачиваем версию JournalTraceNormal.exe через канал «Для проверки» Discord сервера Fear-Project.

// Порядок действий:
1. Слева сверху нажимаем: Drive ➔ Select ➔ выбираем диск (C:) ➔ Select.
2. Нажимаем: Drive ➔ Scan. Ждем сканирование.
3. В меню выбираем: Layout ➔ Data Grid.
4. В строку поиска вводим названия читов: exloader, xone, memesense, midnight, neverlose и т.д.
5. Внимательно смотрим события файловой системы и обязательно сверяем даты!

Пояснение по правилам Fear Project

Официальные статьи для вынесения вердикта

ПРАВИЛО 1.1 Активный чит
  • ExLoader запущен менее 72 часов (3 суток) назад.
  • Любой чит, запущенный в данный момент.
  • SkinChanger (скины в игре без Steam инвентаря).
ПРАВИЛО 1.2 Хранение / Следы
  • ExLoader запущен более 72 часов назад, но не более 14 дней.
  • Чит был удален менее чем 7 дней назад (в Корзине / Shellbags).
ПРАВИЛО 1.3 Отказ / Саботаж
  • Отказ скачивать и запускать FearSteamScan.exe.
  • Отказ вставить подозрительную флешку.
  • Выход из игры или звонка во время проверки.
